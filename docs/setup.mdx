## First run

Open **PowerShell** (administrator rights are not required) and paste:

```powershell
irm https://raw.githubusercontent.com/kud/shadow-box-bootstrap/master/bootstrap.ps1 | iex
```

The bootstrap makes sure `winget` is registered, installs Git and PowerShell 7, clones the repository to `%USERPROFILE%\shadow-box-bootstrap` and runs `shadow install`. Installers that need administrator rights raise their own Windows prompt.

## Updating

```powershell
~\shadow-box-bootstrap\shadow update
```

`update` pulls the latest version of the repository, installs anything newly listed, upgrades outdated packages and applies the settings that are switched on. Game launchers are marked as self-updating, so `update` leaves them alone.

| Command          | Does                                                 |
| ---------------- | ---------------------------------------------------- |
| `shadow install` | install everything missing, apply enabled settings    |
| `shadow update`  | pull the repo, then install, upgrade, apply settings  |
| `shadow status`  | show what is missing or not applied, change nothing   |
| `shadow check`   | validate the `config/` files                          |

`-DryRun` previews `install` or `update` without changing anything. Every run writes a log to `%LOCALAPPDATA%\shadow-box-bootstrap\logs`.

## Adding a package

Look up the winget id with `winget search <name>`, then add a line to `config/packages.psd1`:

```powershell
@{ Id = 'Discord.Discord'; Name = 'Discord'; Upgrade = $false }
```

`Upgrade = $false` marks an application that updates itself. Software that winget lacks goes under `Scoop`, which is installed the first time it is needed. Removing a line stops managing a package without uninstalling it.

| ----------------------------- | ------------------- | -------------------- |
| `Vicinae.Vicinae`             | Vicinae (launcher)  | yes                  |

| `EpicGames.EpicGamesLauncher` | Epic Games Launcher | self-updating        |
| `ElectronicArts.EADesktop`    | EA app              | self-updating        |

PowerToys, GOG Galaxy, Ubisoft Connect and Discord are listed but commented out. The EA app replaces Origin, which EA has retired.

## Opt-in Windows settings

`config/settings.psd1` lists a few gaming-oriented tweaks: visible file extensions, dark mode, Game Mode, no Game Bar background recording and raw mouse input. **Every one ships disabled.** Setting `Enabled = $true` and running `shadow update` applies it. Tweaks write only to the current user's registry (`HKCU`) and are rewritten only when the value differs.

## GPU drivers

GPU drivers are left alone: the Shadow image is generally provisioned with its driver, and replacing it by hand on a cloud machine risks more than it gains. NVIDIA has replaced GeForce Experience with the NVIDIA app, which winget does not carry.
