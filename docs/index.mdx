**shadow-box-bootstrap** sets up a Windows [Shadow](https://shadow.tech) PC for gaming and keeps it current. One command installs everything on a fresh machine; one command updates it later. The list of applications and the optional Windows settings live in two plain files under `config/`, so changing the machine means editing a line rather than a script.

Every run is idempotent: it installs what is missing, upgrades what is outdated and leaves the rest alone, so it is safe to repeat at any time. Packages come from `winget`, which ships with Windows, with [Scoop](https://scoop.sh) as a fallback for anything winget does not carry.
