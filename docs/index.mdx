**shadow-box-bootstrap** is a setup recipe for a Windows shadow box: two commands, run from an elevated prompt, that take a clean Windows 10 or 11 install to a working machine with the tools and game launchers already in place.

There is no script to download and nothing to configure. The whole recipe lives in a single page, so it reads in a minute and repeats the same way every time.
